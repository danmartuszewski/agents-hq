Voice input off

Enable voice input (dictate to sessions)
Optional, off by default — nothing here is needed to use the dashboard. When on, a mic button lets you dictate a message: your audio is sent to OpenAI for transcription (needs an OpenAI key) and the text goes to the session you name (or the one that last replied) as if you'd typed it, running with that session's permissions. The switch applies to every open dashboard tab; turning it off closes the mic and drops anything queued.
Auto-send after silence (hands-free)
When on, dictation sends itself after you stop talking — no second click. Off (default) means you click the mic again to send. Per-device preference.
Answer after each reply (hands-free)
When a reply finishes, the mic opens automatically so you can answer back — no click, no trigger word. Stay silent and it closes on its own. Routes your answer to the session that just replied. Per-device preference.
Speak a confirmation before sending
Says "Sending your message to «project»" before it injects, with a brief cancel window. Off (default) is silent — you still get the send beep and the on-screen routing toast.

Output

Show agent output in detail panel
Shows each agent's finished response in its detail panel — clean and readable instead of raw console text. Local render only, no API call.
Enable AI formatting (uses Claude)
Adds an "✨ Enhance" button in the expanded output that reformats it into richer, themed HTML using a quick Claude model. On-demand only — nothing runs until you click it. Falls back to the local render.
